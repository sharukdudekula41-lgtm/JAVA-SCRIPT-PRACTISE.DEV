CSS ASSIGNMENT 1

  1. What is global selector ? and explain with example

    • The global selectors (*) selects all elements in web page
    • it used to apply common styles like margin,padding,or font styles
    • Example: * { margin: 0; padding: 0; }
  2. What is a tag/element selector? Explain with five example
    • it selects HTML elements based on their tag name.it applies the same style to all elements of that type of tags
    • Example: h1 { color: blue; }
    • Example: p { font-size: 16px; }
    • Example: div { background-color: lightgray; }
    • Example: span { font-weight: bold; }
    • Example: img { border: 1px solid #ccc; }
  3. What is a class selector? Explain with examples
    • A Class selector is used to style elemnts with a specific class. it is written using dot(.)
    • Example: .my-class { color: red; }
    • Example: .container { width: 100%; }
  4. What is an ID selector? Explain with examples
    • An ID selector is used to style a single, unique element on a page. it is written using a hash symbol (#)
    • Example: #my-id { color: blue; }
    • Example: #header { background-color: #f0f0f0; }
  5. What is powerful selctors in CSS?
    • Powerful selectors in CSS are those that allow you to target elements based on specific criteria, such as their attributes, position in the document, or relationship to other elements.
    • Examples of powerful selectors include:
    • Attribute Selector: input[type="text"] { border: 1px solid #ccc; }
    • Child Selector: div > p { color: green; }
    • Adjacent Sibling Selector: h2 + p { font-size: 18px; }
    • General Sibling Selector: h2 ~ p { color: gray; }
  6. Explain the different types of combinators in CSS?
    • Combinators in CSS are used to combine multiple selectors to target elements based on their relationship in the document structure.
    • Types of combinators include:
    • Descendant Combinator (space): div p { color: blue; }
    • Child Combinator (> ): div > p { color: red; }
    • Adjacent Sibling Combinator (+): h2 + p { font-size: 18px; }
    • General Sibling Combinator (~): h2 ~ p { color: gray; }
  7. Give an example of when you would use each combinator?
    • Descendant Combinator: To style all paragraphs inside a div: div p { color: blue; }
    • Child Combinator: To style only direct child paragraphs of a div: div > p { color: red; }
    • Adjacent Sibling Combinator: To style the first paragraph immediately following an h2: h2 + p { font-size: 18px; }
    • General Sibling Combinator: To style all paragraphs that are siblings of an h2: h2 ~ p { color: gray; }
  8. Explain the difference between id, class and element selectors?
    • Element Selector: Targets all elements of a specific type (e.g., h1 { color: blue; })
    • Class Selector: Targets elements with a specific class (e.g., .my-class { color: red; })
    • ID Selector: Targets a single, unique element with a specific ID (e.g., #my-id { color: blue; })
  9. What is the *Selector used for?
    • The * selector, also known as the universal selector, is used to select all elements in a document. It applies the specified styles to every element on the page.
    • Example: * { margin: 0; padding: 0; } - This example resets the margin and padding for all elements to zero.
  10. How would you override a style applied by an ID selector with a class selector?
    • To override a style applied by an ID selector with a class selector, you can increase the specificity of the class selector or use the !important declaration.
    • Example using increased specificity: #my-id { color: blue; } .my-class { color: red; } - In this case, the ID selector has higher specificity, so the color will be blue. To override it, you can make the class selector more specific: #my-id.my-class { color: red; }
    • Example using !important: #my-id { color: blue; } .my-class { color: red !important; } - In this case, the !important declaration will override the ID selector, and the color will be red.
  11. How do sibling selectors work in css? can you give an example?
    • Sibling selectors in CSS allow you to target elements that are siblings of each other in the document structure.
    • Example: h2 + p { font-size: 18px; } - This styles the first paragraph that immediately follows an h2 element.
  12. How would you target an element with multiple classes?
    • To target an element with multiple classes, you can combine the class selectors in your CSS rule. For example, if you have an element with the classes "class1" and "class2", you can target it like this: .class1.class2 { color: red; }
    • This will apply the specified styles to any element that has both "class1" and "class2" classes.
  13. How do you select all list-items inside an ul element?
    • To select all list items inside a ul element, you can use the descendant selector in CSS. The syntax would be: ul li { /* styles here */ }
    • This will apply the specified styles to all li elements that are descendants of a ul element.
